# 報名確認與付款通知信模板

此模板用於收到 Google 表單報名後，由主辦單位回信給學員。

金額請以 Google 表單回覆試算表 `表單回覆 2` 的欄位為準：

- `R` 房型總價 / Total Fee
- `S` 訂金 / Deposit
- `T` 尾款 / Balance

試算表：

`https://docs.google.com/spreadsheets/d/1njhAvw1A7E4nF32-M7QRxj2w7vMxSS_GM402Ed0TgKc/edit?gid=1106960327`

## 中文

主旨：越南七日覺醒僻靜營｜報名確認與訂金付款通知

您好，{學員姓名}：

我們已收到您的報名資料。

您選擇的住宿方案為：

{房型名稱}

費用明細如下：

- 房型總價：NT${房型總價}
- 訂金：NT$15,000
- 尾款：NT${尾款}
- 尾款截止日：2026/10/1

請先完成訂金付款。訂金完成後，主辦單位會依報名與付款順序保留房型與名額。

匯款資訊：

銀行：
戶名：
帳號：

完成匯款後，請回覆匯款後五碼，方便我們核對。

取消政策提醒：

- 2026/9/30 前取消：扣除訂金後，其餘已繳費用全額退還。
- 2026/10/1～11/17 取消：扣除訂金後，其餘已繳費用退還 80%。
- 2026/11/18 起取消：已繳費用不予退還。

提醒：訂金不可退還，可轉讓他人，轉讓前請先告知主辦單位。
